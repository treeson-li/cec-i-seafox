# 技术说明

## 1. 磁带格式

两面磁带内容相同（B 面整体比 A 面早约 2.6 秒），各有 4 条记录：

| 记录 | A 面同步位置 | 格式 | 装入范围 | 运行时位置 |
|---|---|---|---|---|
| R1 | 11.96s | 标准 Apple II Monitor 读带格式 | `$0030-$03FF` | 原地 |
| R2 | 20.24s | 自定义分块格式 | `$0800-$0950` | 原地 |
| R3 | 24.97s | 同上 | `$0800-$1FFF` | `$0900` 起保留 |
| R4 | 61.24s | 同上 | `$4000-$AA01` | 先搬到 `$2000`，再部分重定位 |

- 自定义格式由 R1 里的装带例程（`$0200`）实现：借用 Monitor 的 `$FCEC`/`$FCFA`/`$FCFD`/`$FCC9` 逐字节读带，**每 256 字节跟一个 XOR 校验字节**，初值 `$FF`，每块重置；最后不满 256 字节的块没有校验。
- 两面共 131 个块校验全部通过，R1 的标准校验也通过。
- 每段读完后 `JMP $FDED`，借 CSW 钩子 `$36/$37` 跳到下一阶段：`$0300` → `$0800`（R2，显示标题）→ `$034E` 装 R4 → `$2900` 重定位 → **`$67D4` 游戏入口**。
- 位判决：0 周期最长 544µs，1 周期最短 770µs，阈值 750µs。

`tools/research/` 里的脚本可以复现这些结果：`scan.py` 找 leader 和同步，`decode3.py` 解码，`deblock.py` 去掉校验字节、按地址还原，`memmap.py` 合成 `$67D4` 时刻的内存，`basescore.py`/`trace.py` 推断装载基址和追踪指令。

## 2. 在 MAME 中装载

`ceci` 驱动要点（MAME 0.289）：

- 磁带设备在 Lua 里的标签是 `:tape`，不是 `:cassette`。
- 扩展槽是 `sl1`、`sl2`、`sl4`、`sl5`、`sl7`；没有 `sl3`（`$C300` 是主板汉字固件），`sl6` 是内置 Disk II 控制器，不能移除，所以需要 `a2diskiing`、`d2fdc` 的 ROM。
- 开机后至少等 3 秒再输入，否则按键会丢。

装载命令：

```
POKE 60,48:POKE 61,0:POKE 62,255:POKE 63,3:CALL 53574
```

即把 A1 设为 `$0030`、A2 设为 `$03FF`，再调用 CEC-I ROM 中兼容 Apple 的读带例程 `$D146`，相当于 Monitor 的 `30.3FFR`。之后放带，到 leader 中段按回车。`tools/play_seafox.lua` 在装载期间关闭限速，CPU 进入 `$2900` 重定位时停带并恢复正常速度。

Lua 编程注意：`install_read_tap` 返回的句柄必须存进全局变量，否则会被垃圾回收，tap 随之失效。`m.time.seconds` 只有整数秒，要精确时间用 `m.time:as_double()`。

## 3. 游戏内部

| 地址 | 含义 |
|---|---|
| `$7043` | 键盘处理：读 `$C000`，Esc 暂停、Ctrl-S 声音、Ctrl-H/Ctrl-V 反转左右/上下、空格开始 |
| `$7190` | 键表，11 项 ×（键字符指针, dx, dy）；指针指向屏幕上的按键说明文字，dx=`$80` 向前开火，`$81` 向上开火 |
| `$7E15`/`$7E16` | 潜艇速度 dx/dy（锁存；撞到边界时被游戏清零） |
| `$71C1`/`$71BF` | 游戏进行中 / 键盘模式（演示画面时为 0；按游戏杆按钮开始则是游戏杆模式） |
| `$784C` | 向上发射：`$7EC1` < `$7EC2`（原版 1）才能发射 |
| `$78ED` | 向前发射：`$7F8D` < `$7F8E`（原版 1），另有冷却 `$7F92` |
| `$14EF` | 弹药（BCD） |
| `$14F0`/`$14F1` | 油量（BCD，低位在前） |
| `$7D25` | 扣油：每 `$7E1E`+1（=9）个节拍减 `$7E1B`（BCD 10） |
| `$7E19`/`$7E1A`、`$7E1F` | 加油船补给时恢复的满油量、满弹药 |
| `$16A6`、`$16A8` | 对象表：已用槽数、起始地址（32 槽 × 8 字节）；添加对象时不检查是否已满 |
| `$6680`/`$6681` | 声音：`$6680` 为发声地址偏移（`$20` = `$C030` 扬声器，0 = 静音），演示画面时为 0 |

## 4. 修改版的实现

全部通过 MAME Lua 的读 tap 实现，不修改内存中的游戏代码：

- **按键**（`seafox_controls.lua`）：游戏进行中（`$71C1` 非 0）空格注入向上发射键，F 注入向前发射键，D 注入带"向左"标记的向前发射键，回车注入 Esc（游戏的暂停键，暂停后等任意键继续，所以再按回车即继续）；同时屏蔽模拟键盘上的空格/D/F/回车，避免重复或误触继续。演示画面不注入开火，空格原样传给游戏去开局。
- **方向键**（`seafox_controls.lua`）：每帧读主机方向键，合成 8 方向，稳定 3 帧后从游戏自己的键表查出对应字符，注入 `$C000` 的读取结果，游戏读 `$C010` 清选通时出队。方向只保留最新一条，开火键 0.3 秒内没被读走就作废（开场驶入动画期间游戏不读键）。方向键在模拟键盘上产生的 `$88`/`$95`/`$8B`/`$8A` 被屏蔽，因为 `$88` 就是 Ctrl-H。
- **开火限制**（`seafox_patches.lua`）：`$7EC2`、`$7F8E` 各只在开火检查时读一次，tap 让它读出放宽后的上限；对象表用到 24 槽时读出 0，暂停开火，给敌人留出槽位。
- **向左发射**（`seafox_leftfire.lua`）：把 `$8C09` 的鱼雷形状描述符（+5 宽字节数、+6 高、+7 每个移位副本字节数、+8 起 7 个移位副本）左右镜像，重新生成移位副本放到 `$0300`（游戏运行时这块内存实测无读写）；生成前先用同样方法重建原图并与游戏数据比对，自检不通过就退回原图形。游戏在 `$79AF` 写 `$1D6C,Y` 完成对象创建时，若控制层正在处理的键带向左标记，就把该对象的形状指针改成 `$0300`、起点移到潜艇左侧。形状指针同时作为方向标记，对象表压缩时随对象一起搬移。移动由 `$7F24` 的 `ADC $7F8A` 完成：此时低字节已在 A 里，所以 tap 返回 `-4`，并预先把高字节减 1 抵消进位；越过左边界后 x 回绕到 `$FFxx`，游戏自己的右边界检查会把它移除。
- **油耗**（`seafox_patches.lua`）：`$7E1B` 只在扣油指令里读一次，停船（`$7E15`、`$7E16` 都为 0）时读出 5；扣量不超过剩余油量，防止 BCD 下溢成 9995。

调试用环境变量：`SEAFOX_FAKE_KEYS="秒:键,键;..."` 用脚本模拟按键（键名 `up`/`down`/`left`/`right`/`fire_fwd`/`fire_up`），`SEAFOX_DEBUG=1` 打印游戏实际读到的键。

## 5. 未解决

- **后期关卡变慢**：游戏没有定时器，东西一多就慢。理论上可以超频模拟的 CPU，再给主循环加一个等待屏幕刷新的节拍器，但 MAME 0.289 的 Lua 接口不能调 CPU 频率，没有做。
